# Hệ thống bán hàng

Khung ban đầu cho website bán hàng, dựa trên ERD do nhóm cung cấp.

## Cấu trúc thư mục

- `frontend/`: giao diện người dùng.
- `backend/`: API và xử lý nghiệp vụ.
- `database/`: migration và dữ liệu mẫu.
- `docs/erd/`: sơ đồ ERD và tài liệu dữ liệu.

## Tài liệu

- [ERD hệ thống bán hàng](docs/erd/sales-system-erd.png)

## Trạng thái

Repo hiện chứa cấu trúc khởi đầu và ERD. Công nghệ frontend, backend và cơ sở dữ liệu sẽ được chọn ở bước tiếp theo.
